# csv-tidy

汚れた CSV を整形する Node.js 製の CLI です。外部ライブラリは使っていません。

- 文字コード（UTF-8 / Shift_JIS / EUC-JP、BOM 付き含む）を自動判定し、UTF-8 で出力
- 全項目の前後の空白（全角空白を含む）を削除
- 日付らしい列を判定し、`YYYY-MM-DD` に統一（和暦にも対応）
- 完全に重複した行を削除
- 何件直したかを最後に表示

元の CSV は上書きしません。結果は常に別ファイルに出力します。

## 必要なもの

Node.js 18 以上

## 使い方

```sh
node bin/csv-tidy.js <input.csv> [-o <output.csv>] [--force] [--bom]
```

| オプション | 説明 |
|---|---|
| `-o`, `--output` | 出力先。省略時は入力と同じフォルダの `<ファイル名>.tidy.csv` |
| `--force` | 出力先が既にあれば上書きする（なければエラー） |
| `--bom` | UTF-8 BOM を付けて出力する（Excel で開く場合に便利） |
| `-h`, `--help` | ヘルプを表示する |

`npm link` すれば `csv-tidy` コマンドとしても使えます。

```sh
node bin/csv-tidy.js samples/customers_dirty.csv
```

```
入力: samples/customers_dirty.csv (Shift_JIS, データ 25 行)
出力: samples/customers_dirty.tidy.csv (UTF-8, データ 20 行)
空白を削除したセル: 8 件
日付を統一したセル: 21 件（列: 登録日）
削除した重複行: 5 件
変換できなかった日付: 0 件
```

件数は stderr に出力されます。日付列の中に変換できない値があった場合は、値を元のまま残し、行番号と値を表示します。

## 日付の判定と対応形式

空でない値のうち 80% 以上を日付として読める列を、日付列とみなします。全角数字や日付内の空白は、変換前に取り除きます。

| 形式 | 例 | 変換後 |
|---|---|---|
| 区切り `-` `/` `.` | `2023/4/5`, `2023.8.19` | `2023-04-05`, `2023-08-19` |
| 年月日 | `2023年7月15日` | `2023-07-15` |
| 8 桁 | `20230802` | `2023-08-02` |
| 2 桁の年 | `24/9/15` | `2024-09-15`（2000 年代とみなす） |
| 和暦 | `令和5年5月20日`, `令和元年5月1日` | `2023-05-20`, `2019-05-01` |
| 和暦（頭文字） | `R5.6.3`, `H30/12/3` | `2023-06-03`, `2018-12-03` |

和暦は明治・大正・昭和・平成・令和（`M` `T` `S` `H` `R`）に対応しています。`2023/2/29` のような実在しない日付は変換しません。元号の期間外の日付（例: `平成31年5月1日`）は、エラーにせずそのまま西暦に換算します。
